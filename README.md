# awesome-fonts

[![CI](https://github.com/zetaloop/awesome-fonts/actions/workflows/ci.yml/badge.svg)](https://github.com/zetaloop/awesome-fonts/actions/workflows/ci.yml) [![Update](https://github.com/zetaloop/awesome-fonts/actions/workflows/update.yml/badge.svg)](https://github.com/zetaloop/awesome-fonts/actions/workflows/update.yml)

Fonts for Scoop and Homebrew.

## Install

### Scoop

```powershell
scoop bucket add awesome-fonts https://github.com/zetaloop/awesome-fonts
scoop install awesome-fonts/font-maple-mono
```

All fonts:

```powershell
scoop bucket add awesome-fonts https://github.com/zetaloop/awesome-fonts && scoop install awesome-fonts/font-alibaba-puhuiti awesome-fonts/font-fira-code awesome-fonts/font-harmonyos-sans awesome-fonts/font-iosevka-aile awesome-fonts/font-iosevka-etoile awesome-fonts/font-iosevka-sgr awesome-fonts/font-iosevka-sgr-slab awesome-fonts/font-iosevka-sgr-term awesome-fonts/font-iosevka-sgr-term-slab awesome-fonts/font-jetbrains-mono awesome-fonts/font-lxgw-bright awesome-fonts/font-lxgw-bright-code awesome-fonts/font-lxgw-marker-gothic awesome-fonts/font-lxgw-neoxihei awesome-fonts/font-lxgw-neoxihei-plus awesome-fonts/font-lxgw-neozhisong awesome-fonts/font-lxgw-neozhisong-plus awesome-fonts/font-lxgw-wenkai awesome-fonts/font-lxgw-wenkai-lite awesome-fonts/font-maple-mono awesome-fonts/font-maple-mono-nf-cn awesome-fonts/font-maple-mono-normal awesome-fonts/font-maple-mono-normal-nf-cn awesome-fonts/font-misans awesome-fonts/font-misans-l3 awesome-fonts/font-misans-tc awesome-fonts/font-monaspace awesome-fonts/font-montserrat awesome-fonts/font-mulish awesome-fonts/font-space-grotesk awesome-fonts/font-varela awesome-fonts/font-varela-round awesome-fonts/font-victor-mono
```

### Homebrew

```sh
brew tap zetaloop/awesome-fonts
brew install --cask zetaloop/awesome-fonts/font-maple-mono
```

All fonts:

